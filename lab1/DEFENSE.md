# Захист лабораторної роботи №1: Моделювання даних

## 1. Обґрунтування нормалізації
Модель відповідає 3NF. Сутність Order_Item містить атрибут UnitPrice, який фіксує вартість товару на момент створення замовлення. Це запобігає аномаліям оновлення при зміні ціни у таблиці Product.

## 2. Ідентифікатори та масштабованість
Усі PK та FK типізовані як UUID, що дозволяє уникнути колізій при розподіленій архітектурі та забезпечує безпеку ідентифікаторів у REST API.
